🔴 SYMPTOM: Logs show but scene doesn't load
═══════════════════════════════════════════════════════════════════════════════

You see these logs:
  === Case 1 (English) selected ===
  ✓ GameManager found, setting URL to: http://127.0.0.1:8000
  ✓ Starting coroutine for scene: CrimeSceneLevel
  🔄 StartGameRoutine called:
  📡 Calling server: http://127.0.0.1:8000/start-game

But then... nothing happens. Scene doesn't load.


🎯 ROOT CAUSE: Server Not Running or Request Hanging
═══════════════════════════════════════════════════════════════════════════════

The coroutine is waiting for the server response. If the server is:
1. ❌ Not running → Request will timeout (10 seconds)
2. ❌ Running on wrong port → Connection refused
3. ❌ Slow to respond → Long wait time


✅ SOLUTION #1: Test Server Connection (Recommended First)
═══════════════════════════════════════════════════════════════════════════════

1. Open MainScene.unity in Unity
2. Create empty GameObject named "ServerTester"
3. Add Component → TestServerConnection
4. Enter Play mode
5. Press SPACE (test English server) or T (test Thai server)
6. Check Console for results

This will tell you immediately if the server is running!


✅ SOLUTION #2: Start the Server
═══════════════════════════════════════════════════════════════════════════════

Open a NEW terminal (separate from Unity):

```bash
cd Backend/rag

# Check if you have API key set
echo $GROQ_API_KEY

# If empty, set it:
export GROQ_API_KEY="your-groq-api-key-here"

# Start English server
uvicorn server:app --reload --host 127.0.0.1 --port 8000
```

You should see:
  INFO: Uvicorn running on http://127.0.0.1:8000


✅ SOLUTION #3: Quick Server Test (Terminal)
═══════════════════════════════════════════════════════════════════════════════

In a terminal, test if server responds:

```bash
# Test English server
curl http://127.0.0.1:8000/start-game -X POST

# If you see: {"status":"ok"} or similar → Server is running! ✅
# If you see: Connection refused → Server is NOT running ❌
```

🐛 COMMON MISTAKES
═══════════════════════════════════════════════════════════════════════════════

❌ Wrong: uvicorn server:app (uses default port, might conflict)
✅ Right: uvicorn server:app --port 8000

❌ Wrong: Running both servers in same terminal
✅ Right: Two separate terminals or use tmux

❌ Wrong: Server running but on wrong port (e.g., 8000 instead of 8001)
✅ Right: Check Unity Console for which URL it's trying

❌ Wrong: Scene name is "CrimeSceneLevel.unity" (with extension)
✅ Right: Scene name is "CrimeSceneLevel" (no extension)
